# 開発PM AI支援システム (PoC)

AIを活用した開発プロジェクトマネージャー向け業務支援システムのPoC（Proof of Concept）です。

## 機能

| 機能 | 説明 |
|------|------|
| **AIチャットアシスタント** | 開発PM業務に特化した対話型AI。プロジェクト管理の質問・相談に対応 |
| **ステータスレポート生成** | プロジェクト情報を入力し、構造化されたステータスレポートを自動生成 |
| **リスク分析** | プロジェクト状況からリスクを特定し、影響度・対策を提案 |
| **会議議事録作成** | 会議メモから議事録を整形、アクションアイテムを抽出 |
| **タスク分解支援** | 大きなタスクを具体的なサブタスクに分解（見積もり・優先度付き） |

## 技術スタック

- **Backend**: Python / FastAPI
- **Frontend**: HTML / CSS / JavaScript
- **AI**: OpenAI API (GPT-4o-mini)

## セットアップ

### 前提条件

- Python 3.11+
- OpenAI API Key

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/naga-power/pm-ai-assistant.git
cd pm-ai-assistant

# 依存関係をインストール
pip install -e .

# 環境変数を設定
export OPENAI_API_KEY="your-api-key-here"

# （オプション）モデルを変更する場合
export OPENAI_MODEL="gpt-4o"
```

### 起動

```bash
# 開発サーバーを起動
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

ブラウザで http://localhost:8000 にアクセスしてください。

## 使い方

### 1. AIチャット
左サイドバーの「AIチャット」を選択し、プロジェクト管理に関する質問や相談を入力します。

### 2. ステータスレポート生成
「レポート生成」画面でプロジェクト情報を入力し、「レポートを生成」ボタンをクリックします。

### 3. リスク分析
「リスク分析」画面でプロジェクトの概要と現状を入力し、「リスクを分析」ボタンをクリックします。

### 4. 会議議事録
「議事録作成」画面に会議中のメモを貼り付け、「議事録を生成」ボタンをクリックします。

### 5. タスク分解
「タスク分解」画面に分解したいタスクを入力し、「タスクを分解」ボタンをクリックします。

## PoC → 本格導入に向けて

このPoCでは、開発PM業務におけるAI支援の可能性を体験していただけます。
本格導入に向けては、以下の拡張が可能です：

- **カスタマイズ**: お客様の業務フローに合わせたプロンプト・テンプレートの調整
- **データ連携**: Jira, Backlog, GitHub Issues等との連携
- **ナレッジベース**: 社内のプロジェクト知見を学習
- **権限管理**: ユーザー認証・アクセス制御
- **レポート履歴**: 過去の生成物の保存・検索
- **他領域への展開**: 営業、人事、カスタマーサポート等への適用
